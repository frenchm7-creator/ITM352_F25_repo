# Quiz Web App: Assignment 3 (Flask)

## Overview
This Flask web application converts the console-based quiz from Assignment 1 into a browser-based quiz. It implements persistent user identification (sessions) and a global leaderboard.

## Install
1. Create and activate a Python virtual environment.
2. `pip install -r requirements.txt`

## Run
From the project root:
```bash
export FLASK_APP=app.py
flask run
