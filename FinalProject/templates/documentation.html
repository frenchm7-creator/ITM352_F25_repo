Getting Started

This tool helps you clean and analyze inventory data from CSV or Excel files.

Step 1: Upload Your File

Navigate to the Upload page and select your CSV or Excel file. Make sure your file has headers in the first row.

Step 2: View Results

After processing, you'll see a data quality report including:

  • Missing values count for each column
  • Duplicate rows detection
  • Overall quality score
  • Basic visualizations

Step 3: Advanced Analysis

Visit the Analysis page to see:

  • Multiple chart types (bar, histogram, box plots)
  • Statistical summaries
  • Correlation analysis

Step 4: Anomaly Detection

The Anomaly Detection feature uses Isolation Forest algorithm to identify unusual data points that may need attention.

Technical Requirements

  • Python 3.7+
  • Flask web framework
  • Pandas for data processing
  • Matplotlib for visualizations
  • Scikit-learn for anomaly detection

Features

  • File upload (CSV/Excel)
  • Missing value detection
  • Duplicate detection
  • Data quality scoring
  • Multiple visualizations
  • Anomaly detection (ML-based)
  • Statistical analysis
