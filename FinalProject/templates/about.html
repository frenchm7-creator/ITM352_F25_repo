About Inventory Cleaner

Project Overview

Inventory Cleaner is a web-based tool designed to help users clean and analyze inventory data efficiently. This project was created as part of the ITM352 Capstone assignment.

Purpose

Many businesses maintain inventory data in spreadsheets that often contain errors like:

  • Missing values
  • Duplicate entries
  • Out-of-range values
  • Inconsistent formatting

This tool automates the detection of these issues and provides visualizations to help users understand their data better.

Key Features

  • Data Validation: Automatically detect missing values and duplicates
  • Quality Scoring: Calculate an overall data quality score
  • Visualizations: Generate charts to understand data distribution
  • Anomaly Detection: Use machine learning to identify unusual patterns
  • Multi-format Support: Accept both CSV and Excel files

Technologies Used

  • Backend: Python, Flask
  • Data Processing: Pandas, NumPy
  • Visualization: Matplotlib
  • Machine Learning: Scikit-learn (Isolation Forest)
  • Frontend: HTML, CSS, Font Awesome

Project Information

Course: ITM352 - Software Engineering II

Assignment: Capstone Project

Year: 2025
