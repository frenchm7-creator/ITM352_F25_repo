# PROJECT PROPOSAL - Inventory Cleaner

## 1. Purpose of the Program
The purpose of my program is to help users clean and check inventory data from a CSV or Excel file. Many people keep their inventory in spreadsheets, and these files often have mistakes like missing values, duplicates, or numbers that look wrong. My program will make this easier by letting the user upload a file and then showing them what issues it finds, along with a simple summary and some charts.

## 2. Main Features
- Upload a CSV or XLSX file
- Check for missing values
- Check for duplicates
- Identify unusual or out-of-range values
- Show a summary of the inventory
- Generate simple charts (like bar charts)
- Display everything on a basic Flask webpage
- Stretch goal: use a small anomaly-detection feature to spot odd items

## 3. Implementation Plan
I will build the project using Python, mainly with Pandas, Matplotlib, and Flask. I will create separate functions for loading data, checking for errors, creating charts, and handling each webpage route. The Flask pages will display the results in a simple and easy-to-read format.

For AI use, I will not ask AI to build the full program. Instead, I will use AI when I get stuck, need help fixing errors, or need guidance on why something isn't working. I will still write all the structure and main logic myself. AI will basically help me understand problems faster and explain pieces of code when I need support.

## 4. Testing Plan
I will test the program using multiple inventory files, including ones with missing values or mistakes on purpose. I will also test that the program doesn't crash when a user uploads a bad file. I will check every function one by one and also test the charts and webpage to make sure they display correctly.

## 5. Evidence of Originality

### a. No Full Implementation Online
I searched online using keywords such as: automated data cleaning tool Python, simple data processing assistant, Python CSV fixer app, Python duplicate checker UI, and similar queries.

I found tutorials on individual tasks but no complete application that combines the features we are providing in one beginner-friendly tool.
